# coinductiverepofgraphsceliapicard
Coinductive Representation of Graphs - Code for Celia Picard's PhD thesis

This repository tries to maintain the [Rocq](https://rocq-prover.org/) - formerly Coq - code of Celia Picard's 2012 thesis at Université de Toulouse (formerly University of Toulouse 3).

The thesis advisor was [Ralph Matthes](https://www.irit.fr/~Ralph.Matthes/) who hosts Celia Picard's thesis on his personal web page, at [https://www.irit.fr/~Ralph.Matthes/ThesePicard/](https://www.irit.fr/~Ralph.Matthes/ThesePicard/).

There is a list of correspondances between the thesis text and the code:  (correspondances.pdf)[correspondances.pdf].

Version from 2026, tested with Rocq 9.0.1. The code correspondences with the thesis text are still mostly correct (but three reproved former library lemmas shift everything by a bit). No installation instructions - just run `make` (maybe after `make clean`). The version numbers for all the files are omitted - better trace the version history through GitHub.
